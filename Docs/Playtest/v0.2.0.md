# 플레이테스트 기록 v0.2.0 (데모 v1)

> 설치본만 건네고 설명 없이 끝까지 해보게 한 기록입니다. 관찰자는 옆에서 보기만 했습니다.

## 진행 방식

- **테스터에게 한 말:** "처음 켜서 끝날 때까지 해 주세요. 저는 설명 없이 보기만 할게요. 생각나는 건 말로 해 주시면 좋아요."
- **하지 않은 것:** 조작법 알려주기, 갈 곳 가리키기, 막혔을 때 도와주기. 도와줬다면 관찰 기록에 **개입**으로 적었습니다.
- **기록 방법:** 시간, 본 것(행동), 들은 말을 그대로 적고 해석은 끝난 뒤에 했습니다.
