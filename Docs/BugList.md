# 버그 목록과 우선순위 (4주차 기준, 2026-11-20)

> 근거가 있는 것만 적었습니다. 근거 칸에 "코드 확인"은 소스를 읽어서, "자동 점검"은 설치본 봇 로그로, "확인 필요"는 아직 재현해 보지 않은 것입니다.
> 외부 플레이테스트([v0.2.0 기록](Playtest/v0.2.0.md))는 아직 결과를 적지 않아서, 사람이 플레이하며 찾은 문제는 이 목록에 없습니다.

## 우선순위 기준

| 우선순위 | 기준 | 언제 고치나 |
| --- | --- | --- |
| P0 | 진행 불가, 크래시, 출시(심사) 불가 | 5주차 첫 작업 |
| P1 | 끝까지는 가지만 기획과 다르게 동작하거나 플레이어가 손해를 봄 | 5주차 안에 |
| P2 | 불편하거나 다듬을 부분 | 6주차 전 여유가 있으면, 아니면 출시 후 |

| 1 | P0 | 설치본이 Development 빌드다. STOVE는 언리얼 게임에 Shipping 실행 파일을 쓰라고 안내한다 | 빌드 | `BuildRelease.ps1`의 `-clientconfig=Development`, [STOVE Studio Quick Guide](https://studio-docs.onstove.com/en/pc/GettingStarted/quickguide.html) | 출시 빌드만 Shipping으로 만드는 옵션 추가. ## 이번 주에 고친 문제

| 문제 | 원인 | 조치 | 확인 |
| --- | --- | --- | --- |
| 공격하는 순간 몸이 한 프레임에 홱 돈다 (뒤를 보고 있으면 180°) | 공격할 때 회전을 즉시 적용 | 초당 1800°로 돌림 (뒤돌기 0.1초) | 에디터에서 ABP·C++ 적용 확인 (11/19) |
| 걷기 시작·멈출 때 발이 미끄러진다 | 가속(4096)이 너무 커서 애니메이션 전환보다 먼저 최고 속도에 닿음 | 가속 2000, 대기↔걷기 전환 0.12/0.18초 | 같음 |
| 쿼터뷰에서 락온이 계속 실패해 점검 봇이 사냥 중 쓰러진다 | 커서가 적과 동떨어져 있으면, 마지막 후보인 "몸 앞 60°"도 공격 때 몸이 커서 쪽으로 돌아 비게 됨 | 커서 방향 60° → 범위 안 가장 가까운 적 순으로 찾음 | 봇 재실행: 첫 사냥 1초, 예정 외 사망 0회 (11/20) |
| 박쥐가 아이템을 하나도 떨어뜨리지 않는다 | 드랍 설정을 넣는 스크립트를 돌릴 때 다른 에디터가 박쥐 BP 파일을 잡고 있어 그 파일만 저장 실패 | 에디터를 닫고 다시 저장. 스크립트가 저장 실패를 로그에 남기게 함 | 새 프로세스에서 드랍 10줄 확인, 봇이 날개·송곳니 주움 (11/20) |
| 무기의 마력 보너스가 피해에 반영되지 않는다 | 마법 피해가 오브의 고정값(25)이었음 | 피해 = 오브 피해 × (1 + (마력−5)×5% + 지능×2.5%) | 봇: 마력 7에서 피해 28 (11/20) |

애니메이션 쪽의 자세한 수정 내역(원인 → 결과, 전 → 후, 되돌리는 법)은 [RabbitAnimChanges.md](RabbitAnimChanges.md)에 있습니다.
