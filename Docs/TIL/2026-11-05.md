# TIL 11/5 (목) - 효과음 합성, 헤드리스 파이썬, 자동 플레이 봇

## 반응 연출
이펙트부터 고르지 말고 **그 순간에 뭘 느껴야 하는지**를 먼저 정함

| 순간 | 느낌 | 이펙트 |
| --- | --- | --- |
| 마법 명중 | 맞혔다 | 라벤더색 충격파 + 히트스톱 |
| 처치 | 해냈다 | 보라색 충격파 |
| 카드 획득 | 모았다 | 노란 충격파 |
| 소환 | 동료가 됐다 | 청록색 큰 충격파 |

충격파는 색만 달라도 무슨 순간인지 구분이 된다.

음원을 받아 쓰면 라이선스를 신경 써야 하는데, 파이썬으로 파형을 직접 만들면 그럴 일이 없음.

## 헤드리스 파이썬
에디터를 안 켜고 커맨드라인으로 에셋 슬롯을 채울 수 있다.

```
UnrealEditor-Cmd.exe DarkWolrd.uproject -run=pythonscript -script="스크립트.py" -unattended -nosplash -nullrhi -nop4
```

- 에디터가 꺼져 있어야 함
- `unreal.log()`는 콘솔에 안 나옴 → 결과를 파일로 저장해서 봐야 한다
- `-script` 인자에 역슬래시 쓰면 깨짐 → `/`로
- 저장하고 나서 새 프로세스로 다시 읽어봐야 진짜 저장된 건지 알 수 있음

## 자동 플레이 봇
설치본을 매번 손으로 확인할 수는 없어서 튜토리얼을 끝까지 플레이하는 봇을 만듦

- 순간이동 없이 **실제 키 입력**으로 걷는다 (`PC->InputKey`)
- 2초 막히면 점프, 20초 막히면 실패 처리
- 순간이동으로 점검하면 지형에 끼는 걸 못 찾아서 일부러 걷게 함

돌려보니 바로 문제가 나옴. **소환 구역에서 토끼가 3초 만에 쓰러졌다.**

- HP 50인데 박쥐 4마리가 7.5씩 때림
- 토끼 HP 200, 박쥐 한 방 7로 조정
- 쓰러지면 마지막 목표 지점에서 일어나게 변경

맵을 만든 쪽은 어디서 막히는지 안 보인다는 게 이런 거구나 싶었다.
카드 불빛도 밝기 8000으로 넣었다가 너무 밝아서 1500으로 내림.
