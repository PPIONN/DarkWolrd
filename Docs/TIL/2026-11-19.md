# TIL 11/19 (목) - 인벤토리, 장비, 아이템 드랍

명색이 RPG인데 인벤토리가 없었다. 팰월드 인벤토리 비슷한 화면으로 만듦. 카드·포션·재료에 장비칸까지.

## 구조
- 아이템 하나 = `UItemDefinition`(PrimaryDataAsset). 분류, 희귀도, 장비 칸, 능력치 보너스
- 인벤토리 42칸(7×6), 장비 6칸(무기, 머리, 몸, 신발, 장신구 2)
- 아이템 13종: 물약 2 + 당근, 재료 3, 장비 7
- 시작할 때 물약이랑 당근, 견습 마법봉·견습 로브를 낀 채로

## 장비 보너스는 따로 둔다
장비를 끼면 능력치에 바로 더해 버리면, 저장하고 불러올 때 장비를 다시 끼면서 두 번 쌓인다.
그래서 저장되는 기본 능력치와 장비 보너스(`EquipmentBonus*`)를 따로 두고, 쓸 때만 합침.

## 마력이 피해에 안 쓰이고 있었다
오브 피해가 25로 고정이라 마법봉 마력 +2가 아무 의미가 없었음.

```
피해 = 오브 피해 × (1 + (마력 − 5) × 5% + 지능 × 2.5%)
```

기본 능력치(마력 5, 지능 0)면 1배라 지금 밸런스는 그대로. 견습 마법봉을 끼면 1.1배(28).

## 화면
UMG를 에디터에서 안 그리고 코드로 짬(`RebuildWidget`에서 WidgetTree로).
- 둥근 칸: FSlateBrush RoundedBox + 테두리
- 끌어서 옮기기: `UDragDropOperation`
- 토끼 미리보기: SceneCaptureComponent2D로 토끼만 찍음(ShowOnlyList). 미리보기 조명은 라이팅 채널 1에만 줘서 월드는 안 밝아지게
- UMG 색은 linear라 숫자로 넣은 것보다 화면에서 밝게 나온다. 처음에 너무 떠 보여서 색을 다 어둡게 다시 잡음
- 게임은 안 멈춤(팰월드처럼)

## 아이콘
외부 에셋 안 쓰고, Blender를 창 없이 스크립트로 돌려서 간단한 3D 모형 만들고 렌더링함.
휘어지는 모양은 세로로 잘게 나눠 둬야 제대로 구부러진다.

## 드랍
박쥐가 죽으면 확률로 떨어뜨림(날개 55%, 송곳니 20%, 물약 12~15%, 반지·지팡이 2% 등).
바닥에서 희귀도 색으로 빛나고, 2.6m 안에 오면 끌려와서 주워짐. 주우면 오른쪽에 `+1 박쥐 날개`.

## 삽질
봇을 세 번 돌렸는데 박쥐가 아무것도 안 떨어뜨림.
→ 드랍 설정을 넣는 스크립트를 돌릴 때 다른 에디터가 `BP_Bat.uasset`을 잡고 있어서 저장이 **조용히** 실패했다.

에디터를 다 닫고 다시 돌림. 이제 스크립트가 저장 성공/실패를 로그에 남긴다.
"저장했다"는 로그만 믿지 말고 새 프로세스로 다시 읽어서 확인하기. 2주차에도 배운 건데 또 당함.
