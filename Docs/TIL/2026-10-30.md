# TIL 10/30 (금) - 라이브 리뷰, 기획·스코프 3분 발표

## 발표 준비
3분 대본을 구간으로 나눠서 짰다. 한 구간 40초 안쪽.

| 시간 | 내용 |
| --- | --- |
| 0:00~0:20 | 한 문장 + 장르 |
| 0:20~1:00 | 코어 루프 (처치 → 카드 → 소환) |
| 1:00~1:40 | 뺀 것들 + 다이어트 기준 |
| 1:40~2:30 | 8주 마일스톤 |
| 2:30~3:00 | 현재 상태, 제일 큰 위험 |

3분에 다 넣으려니까 말할 걸 계속 버려야 했음. 이것도 결국 스코프 줄이기랑 똑같다는 생각이 들었다.
