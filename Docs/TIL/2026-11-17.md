# TIL 11/17 (화) - 뛰면서 공격, 달리기·점프 다듬기

## 이동하면서 공격
공격할 때 멈춰 서던 걸 없앰(`bLockMoveOnAttack` 기본 false). 공격 동작은 상체 슬롯에서만 재생.

근데 뛰면서 쏘면 상체가 툭 서고 왼팔이 멈췄다.
- 상체 슬롯이 Spine1부터 위를 공격 클립으로 통째로 바꾸는데, 공격 클립은 서 있는 자세로 만든 것
- 달리기는 상체를 18° 숙이고 팔을 흔드는데, 공격하는 0.6초 동안만 거의 선 자세(5°)가 됨

슬롯 전 이동 자세를 속도에 따라 다시 섞음. 오른팔만 뺌.

| 상태 | 이동 자세 섞는 비율 |
| --- | --- |
| 서 있음 | 0 (상체 전체가 공격 동작) |
| 걷기 | 0.35 |
| 달리기 | 0.7 |

뛸 때는 상체 기울기랑 왼팔은 달리기를 따라가고, 오른팔만 손가락을 튕긴다.

## 달리기가 걷기처럼 보임
요청: "보폭을 넓게, 팔은 ㄴ자 말고 편하게"
- 두 발이 가장 멀어져도 35cm, 초당 5보로 종종거렸음
- 한 주기 12 → 14프레임, 발을 차고 나간 뒤 뒷다리가 잠깐 남았다가 접히게 → 최대 47cm
- 팔은 팔꿈치 80° 고정(ㄴ자) → 뒤에서는 펴지고 앞에서 접히게
- 그다음 요청으로 상체 18 → 26°, 머리도 몸통 숙임을 25% → 65% 따라가게. 앞으로 쏠리는 느낌이 남

실수: "뛸 때 다리를 좀 더 벌렸으면"을 달리기로 알아듣고 고쳤는데, 실제로는 스페이스바 점프 얘기였다. 되돌리고 점프 쪽을 고침. 요청이 애매하면 어느 동작인지 먼저 확인할 것.

## 점프
- 점프 시작 클립이 0.33초인데 전이가 0.3초 남았을 때부터 섞여서 도약이 거의 안 보였음 → 0.08초 남았을 때 0.12초 블렌드로
- 떨어질 때도 무릎을 끌어안고 있다가 착지 순간 다리가 툭 펴짐 → 낙하 클립(JumpFall)을 새로 만들고 떨어지는 속도(Velocity.Z)에 따라 섞음
- 달리다 뛰어도 제자리 점프 자세였음 → 달리던 보폭 그대로 뛰는 클립(JumpStartRun) 추가

## 자연스러움 점검
클립 21개를 숫자로 검사함(반복 이음매, 프레임당 회전, 발 높이, 팔이 몸을 파고드는 깊이). 걸린 것들:
- 공격할 때 몸이 한 프레임에 휙 돎 → 초당 1800°로 돌게. 180° 도는 데 0.1초라 손가락 튕기는 순간 정면을 본다
- 가속 4096이라 0.04초 만에 최고 속도인데 전이는 0.2초 → 그동안 발이 미끄러짐. 가속 2000, 전이 0.12초로
- 서서 카메라를 돌리면 발 붙인 채 제자리에서 빙글 → 50° 넘을 때만 돌고, 돌 때 발 디딤 클립(TurnStep)
- 걷다가 소환하면 다리가 멈춘 채 미끄러짐 → 움직이는 중이면 상체 슬롯으로만 재생
- 명상할 때 발끝이 바닥 아래 6cm

검사에서 손이 배를 11cm 파고든다고 나온 건, 가까이서 찍어 보니 꼬리 주변 면을 잘못 읽은 값이었다. 숫자만 믿지 말고 화면으로 한 번 더 봐야 함.
