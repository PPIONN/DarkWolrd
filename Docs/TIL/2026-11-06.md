# TIL 11/6 (금) - 설치본 v0.1, 빌드 스크립트, 2주차 돌아보기

## 빌드 스크립트
명령 한 줄로 패키징 → 자동 점검 → zip까지 되게 만듦

```
powershell -ExecutionPolicy Bypass -File Scripts\BuildRelease.ps1 -Version 0.1.0
```

- `-prereqs`를 넣으면 VC++ 재배포 패키지가 같이 들어감
- 봇이 실패하면 zip을 안 만들고 멈춤

## 삽질
**한글이 깨지는 스크립트**
Windows PowerShell 5.1은 UTF-8 BOM이 없으면 한글 `.ps1`을 제대로 못 읽음.

**경로에 공백**
`C:\Program Files\...` 때문에 `cmd /c`로 실행하면 따옴표가 꼬인다. `Start-Process`로 바꿈.

**zip이 파일 사용 중이라고 실패**
`DarkWolrd.exe`는 171KB짜리 시작 파일이고 진짜 게임은 따로 뜬다. 이게 먼저 끝나버려서 게임 본체가 파일을 잡고 있었음. 게임 프로세스가 전부 끝날 때까지 기다리게 수정.

**빨간 글씨 NAVMESH NEEDS TO BE REBUILT**
봇이 찍어온 설치본 화면에서 발견.
- 저장된 내비 데이터가 불러올 때 버려지고 있었음
- 다시 구우려고 해도 안 됨
- `RuntimeGeneration=Dynamic`으로 게임 시작할 때 만들게 바꿔서 해결

## 결과
- 쿡 708개, 오류 0개, 경고 0개, 2분 6초
- zip 520MB (풀면 793MB)
- 봇 통과: 빌드 폴더 99초, zip 새로 푼 폴더 65초. 목표 9개 다 달성, 쓰러짐 0회

한글 폴더는 창 없이 돌려서 맵 진입이랑 이동까지만 확인함. 창 없이 돌리면 봇이 마법 단계에서 멈추는데 영문 폴더에서도 똑같아서 경로 문제는 아닌 듯.
