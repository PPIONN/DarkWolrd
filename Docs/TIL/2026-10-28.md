# TIL 10/28 (수) - UE 5.8 업그레이드 + Claude Code MCP 세팅

오늘은 환경 세팅하다가 하루 다 감.

## UE 5.5 → 5.8 업그레이드
5.8에 Unreal MCP 플러그인이 공식으로 들어있다고 해서 올리기로 함.

**업그레이드 전에 한 것**
- 커밋 안 한 에셋들 정리해서 먼저 커밋 (백업용)
- `ue58-upgrade` 브랜치 따로 팜
- 이유: 5.8에서 저장한 에셋은 5.5에서 다시 못 연다. 되돌릴 수 없으니까 브랜치는 필수

**첫 빌드 실패**
```
DarkWolrdEditor modifies the values of properties: [ UndefinedIdentifierWarningLevel ... ].
This is not allowed, as DarkWolrdEditor has build products in common with UnrealEditor.
```
- 원인: `Target.cs`에 5.5 설정이 그대로 남아있었음
- `BuildSettingsVersion.V5` → `V7`
- `EngineIncludeOrderVersion.Unreal5_5` → `Unreal5_8`
- 바꾸고 나니까 빌드 성공. 경고 0개라 C++ 코드는 손댈 게 없었다 (다행)

## Unreal MCP 세팅
- 플러그인 이름이 `ModelContextProtocol` (에디터에는 "Unreal MCP"로 보임), Experimental
- 이것만 켜면 되는 줄 알았는데 **툴셋을 따로 켜야** 실제 기능이 생김
  - EditorToolset, AnimationAssistantToolset, UMGToolSet, NiagaraToolsets 등
- 서버 자동 시작이 기본값 false라서 `DefaultEditorPerProjectUserSettings.ini`에 `bAutoStartServer=True` 추가
- 주소: `http://127.0.0.1:8000/mcp`
- Claude Code에 등록
  ```
  claude mcp add --transport http unreal http://127.0.0.1:8000/mcp
  ```

## 보안 쪽 확인한 것
- 이 MCP 서버는 **인증이 없음**
- 대신 기본 바인딩이 localhost라 외부에서는 못 붙음 (엔진 소스에서 확인함)
- 다른 Origin에서 오는 요청도 막혀 있음

## 삽질
등록하고 Claude Code 재시작했더니 `ECONNREFUSED` 뜸.. 알고 보니 에디터를 안 켜놔서 서버가 없었던 거. 에디터가 켜져 있어야 MCP도 살아있다.
