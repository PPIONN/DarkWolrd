# TIL 11/2 (월) - 튜토리얼 맵 그레이박스

2주차 시작. 이번 주 목표는 **설치본에서 사냥 → 카드 → 소환 → 같이 싸우기**가 돌아가는 것.
그러려면 일단 놀 수 있는 맵이 있어야 해서 튜토리얼 맵부터.

## 지형 만들기
언덕 굴곡이 있는 맵을 원해서 하이트맵으로 감.

- 파이썬으로 높낮이 그림(PNG)을 만들고 → 언리얼 Landscape 모드에서 import
- 크기 252m, 높이는 -14m ~ +46m
- 맵 끝은 언덕으로 막아서 밖으로 못 나가게 함

회색 바닥이라도 굴곡이 있으니까 생각보다 맵 같아 보인다.

## 구역 배치
시작 → 점프 → 조준 → 첫 사냥 → 소환 → 출구, 지그재그로 이어지게 놓음

- 점프 구역: 토끼 점프가 90cm 정도라서 50 / 100 / 150cm 계단으로 맞춤
- 첫 사냥: 박쥐 2마리 스포너
- 소환 구역: 박쥐 4마리 스포너
- 지나가는 길은 가장 가파른 곳이 31도

맵을 짤 때 캐릭터 수치부터 알아야 한다는 걸 처음 알았다. 점프 높이를 모르면 계단 높이를 못 정함.

## 분위기
몽환적이고 어두운 느낌이 컨셉이라 해질녘으로 맞춤
- 낮은 해 + 보랏빛 안개
- 볼류메트릭 포그 켜니까 분위기가 확 달라짐
