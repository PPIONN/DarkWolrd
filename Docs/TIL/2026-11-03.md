# TIL 11/3 (화) - sln, slnx 파일 정체 + 기획 다시 정리

## 못 보던 파일들
폴더에 처음 보는 파일이 늘어나 있어서 뭔지 찾아봄. 5.8로 올리고 프로젝트 파일을 다시 만들 때 생긴 것들이었다.

| 파일 | 정체 | 쓸 일 |
| --- | --- | --- |
| `DarkWolrd.sln` | VS로 C++ 코드 여는 솔루션 파일 (옛날 형식) | 코드 볼 때 |
| `DarkWolrd.slnx` | 위랑 같은 내용의 새 형식 | 둘 중 하나만 열면 됨 |
| `Automation_DarkWolrd.sln` / `.slnx` | 패키징할 때 돌아가는 엔진 쪽 C# 도구 모음 | 내 게임 코드는 안 들어있음. 열 일 없음 |

- `.gitignore`에 `*.sln`, `*.slnx`가 들어있어서 GitHub에는 안 올라감
- 지워도 됨. `.uproject` 우클릭 → Generate Visual Studio project files 하면 다시 생긴다

자동으로 만들어지는 파일이라 신경 안 써도 된다.

## 기획 다시 정리
본격적으로 시작하기 전에 기획이랑 구현할 것을 한번 쭉 정리함

- **구현됨**: 이동, 조준, 마법 공격, 락온, 카드 드롭, 소환, 소환수 자동 전투, 저장
- **코드만 있음**: 필드 보스, 던전, 아레나
- **설계만 있음**: 타이틀, 캐릭터 선택 화면
- **이번 주 할 것**: 튜토리얼 맵에서 루프 돌리기, 설치본 만들기

정리해보니까 또 같은 얘기다. 만든 건 많은데 처음부터 끝까지 이어서 돌려본 건 없음.
이번 주 목표가 딱 그거다. **있는 걸 끝까지 이어 붙이기.**
