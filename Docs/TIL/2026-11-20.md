# TIL 11/20 (금) - 성능 측정, 중간 빌드 v0.3.0, 4주차 돌아보기

## 프레임 시간 재기
봇이 플레이하는 동안 매 프레임 게임 스레드 / 렌더 스레드 / GPU 시간을 기록하게 함.
- `GGameThreadTime`, `GRenderThreadTime`, `RHIGetGPUFrameCycles`
- Build.cs에 `RenderCore`, `RHI` 모듈을 추가해야 함
- 어느 패스가 비싼지는 CSV 프로파일러로: `-csvCaptureFrames=20000 -csvGpuStats`

## 먼저 알게 된 것
- 판마다 260ms짜리 끊김이 12번쯤 → 봇이 찍는 스크린샷 수(12장)랑 같음. 게임 문제가 아니었다
- 개발 PC(RTX 4080 SUPER)는 렌더 스레드가 병목. GPU를 줄여도 fps는 조금만 오른다
- 60fps는 이미 넉넉함. 그래서 목표는 사양 낮은 PC의 GPU 부담 줄이기

## 시도
같은 설치본에 `-ExecCmds`로 설정만 바꿔서 비교

| 시도 | 평균 fps | GPU ms |
| --- | --- | --- |
| 기본(에픽) | 199.2 | 4.16 |
| Lumen 소프트웨어 추적 | 191.5 | 4.45 |
| 레이 트레이싱 끔 | 198.9 | 4.33 |
| TSR 기록 해상도 200→100%, 포그 격자 8→16px | **218.4** | **3.70** |

- TSR 0.735 → 0.415ms, 포그 0.311 → 0.130ms
- 같은 지점 스크린샷을 비교해도 차이를 못 찾음 → `DefaultScalability.ini`에 넣음
- 레이 트레이싱을 꺼도 차이가 없었다. 짐작 말고 재 봐야 한다
