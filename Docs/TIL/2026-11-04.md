# TIL 11/4 (수) - 처음 하는 사람 기준으로 보기, 조작 충돌, 목표 안내

## 키 하나에 액션 두 개
조준할 때마다 토끼가 멈추는 문제가 있었다. 조준 코드를 의심했는데 원인은 키 매핑이었음.

- 우클릭에 **조준**이랑 **명상**이 같이 묶여 있었음
- 명상은 움직이면 안 되는 동작이라 조준할 때마다 같이 켜지면서 멈춘 것
- 명상을 R로 옮겨서 해결

Enhanced Input은 키 하나에 액션 여러 개를 묶어도 에러가 안 난다. 그래서 더 찾기 어려움.

## 화면 알림이 안 보이던 이유
카드 획득, 도감 등록 알림이 디버그 글씨로만 나오고 있었음.

`UGameAnnouncementSubsystem`에 `OnAnnouncement` 델리게이트는 있는데 **받아주는 위젯이 없었다.** 쏘는 쪽만 만들고 받는 쪽을 안 만든 상태.
안내 위젯에서 바인딩해주니까 화면에 나온다.

## 목표 안내 9단계
처음 보는 사람이 설치본만 받아서 해볼 수 있어야 하니까 안내를 넣음

1. 점프 구역으로 이동
2. 조준 구역으로 이동
3. 마법 쏘기
4. 첫 박쥐 잡기
5. 카드 줍기
6. Y로 소환
7. 같이 박쥐 3마리 잡기
8. 출구로 이동
9. 끝

- 위젯은 BP 없이 코드로 그림 (`UCrosshairWidget`과 같은 방식)
- 목표 지점은 노란 표시 + 남은 거리. 화면 밖이면 가장자리에 붙음
- 안내보다 앞서가면 맞는 단계로 건너뜀

## 삽질
조작 안내에 화살표(→)를 썼더니 글자가 이상하게 나옴. 그냥 `4+1`, `4+2`로 바꿈.
