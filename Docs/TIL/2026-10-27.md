# TIL 10/27 (화) - 스코프 정하기, 기능 3분류

## 기능 3분류
반드시 / 있으면 좋음 / 안 해도 됨 으로 나누는 거 배움. 막상 해보니까 제일 어려운 건 "안 해도 됨"에 넣는 거였다..

내 거 기준으로 나눠봄
- **반드시**: 이동·조준·공격, 카드 드롭, 소환 3마리, 몬스터 AI, 필드 보스 1종, 던전 1개, 저장, 타이틀 화면, 패키지 빌드
- **있으면 좋음**: 아레나, 자동 사냥, 카드 등급 강화, 타격감 연출, 게임패드
- **안 해도 됨**: 월드맵, 탈것(비행선/배), 두 번째 캐릭터, 온라인 대전, 장비 강화

원래 모티브로 삼은 옛날 모바일 게임에는 월드맵이랑 탈것이 있어서 꼭 넣고 싶었는데 8주 안에는 무리라고 판단. 나중에.

아레나는 아직 고민 중. 코드는 있는데 검증이 안 돼서 일단 "있으면 좋음".

## 다이어트 기준
기준을 하나로 정함 → **"잡고 → 카드 얻고 → 소환해서 싸운다"에 직접 닿지 않으면 뺀다**

버리는 순서도 미리 정해둠
1. 아레나
2. 게임패드, 토끼 새 애니메이션
3. 던전 방 3개 → 1개
4. 필드 보스 등장 연출

미리 정해두면 나중에 급할 때 고민 안 해도 돼서 좋은 것 같다.
