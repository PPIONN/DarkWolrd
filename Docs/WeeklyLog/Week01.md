# 주간 기록 #1 (10/26~10/30)

> LAUNCH:ER Unreal 3기 · 개인 기록

**범위를 확정하고 개발 환경을 UE 5.8 + Claude Code + MCP로 옮겼습니다.** 과정 시작 시점에 프로젝트는 2026년 6월부터 개발 중이었고, 소환·전투·저장이 구현돼 있었습니다(커밋 28개).

## 이번 주에 한 일

- 1페이지 기획서, 기능 3분류, 다이어트 기준, 8주 마일스톤 작성
- 업그레이드 전 미커밋 에셋을 정리해 백업 커밋하고, 5.8 전용 브랜치 분리
- UE 5.5 → 5.8 업그레이드, C++ 빌드 성공(경고 0개)
- UE 5.8 공식 Unreal MCP 플러그인과 툴셋(에디터·애니메이션·UMG·나이아가라) 활성화, Claude Code에 등록

## 배운 것

- 출시일(심사 신청)에서 거꾸로 짜면 주마다 '무엇을 끝내야 하는지'가 분명해집니다.
- 하고 싶은 기능을 세 칸으로 나누자, 월드맵·탈것·온라인처럼 원래 기획의 큰 부분을 이번 8주에서 뺄 수 있었습니다.
- 엔진 메이저 업그레이드는 되돌릴 수 없으므로(5.8에서 저장한 에셋은 5.5에서 못 엶) 브랜치를 나눠야 합니다.
- Unreal MCP 서버는 인증이 없어서, 로컬에서만 열리는지 엔진 소스에서 확인했습니다.

## 막힌 것과 해결

| 문제 | 원인 | 해결 |
| --- | --- | --- |
| 5.8 첫 빌드 실패 | 빌드 타깃 파일이 5.5 설정(빌드 설정 V5, 인클루드 순서 5.5)을 써서 엔진과 충돌 | V7과 인클루드 순서 5.8로 바꿔 성공 |
| Unreal MCP 연결 거부 | 에디터를 아직 5.8로 열지 않아 서버가 꺼져 있음 | 에디터 실행 후 재확인 (진행 중) |
| 필드 보스·던전이 코드만 있음 | 레벨에 배치해 플레이해 본 적이 없음 | 2주차 최우선 과제로 지정 |

## AI 활용

- Claude Code로 5.8 업그레이드, 빌드 오류 수정, MCP 설정을 진행했습니다.
- 기획서와 마일스톤은 AI 초안을 바탕으로, 범위와 우선순위를 직접 검토해 확정합니다.
