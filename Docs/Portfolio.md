### 3부. 정성: 결정과 문제 해결

각 항목은 "문제 → 선택지 → 고른 것과 이유 → 결과(숫자·화면)" 순서로 씁니다.

1. **카메라를 어깨 뒤에서 쿼터뷰로 바꾼 결정.** 소환수 3마리를 한 화면에서 읽어야 하는데 어깨 뒤 카메라로는 못 읽었다. 턴제 전환안은 일정상 버렸다. 바꾸면서 조준, 락온, 상호작용, 고개 방향까지 다시 짰다. ([주간 기록 #3](WeeklyLog/Week03.md), [#4](WeeklyLog/Week04.md))
2. **자동 점검 봇.** 실제 키 이벤트로 한 판을 끝까지 플레이한다. 지금까지 찾은 문제: 위젯 틱이 창이 그려질 때만 도는 문제, 맵을 다시 저장하면 길찾기 데이터가 비는 문제, 파일 잠금으로 드랍 설정이 저장되지 않은 문제, 쿼터뷰 락온 실패.
3. **헤드리스 애니메이션 파이프라인.** Blender 스크립트로 리그·애니메이션을 만들어 언리얼로 가져오고, 수정마다 원인 → 결과 → 되돌리는 법을 기록했다. ([RabbitAnimChanges.md](RabbitAnimChanges.md))
4. **인벤토리를 위젯 블루프린트 없이 C++로 만든 것.** 아이템 아이콘 13개도 Blender로 직접 모델링·렌더링했다(외부 에셋 0).
5. **성능 개선 1건.** 같은 경로를 도는 봇으로 전후를 비교했다. ([성능 기록](Performance/v0.3.0.md))
6. **AI 도구 활용.** Claude Code와 언리얼 MCP로 에디터 작업까지 자동화한 방법과 한계(에디터 재시작 시 연결 끊김, 스크립트가 두 번 실행되는 문제 등).
