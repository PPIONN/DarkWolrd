# 설치 테스트 결과 — v0.1.0

> 설치본: `DarkWolrd-v0.1.0-Win64.zip`

## 1. 자동 플레이 점검 (개발 PC)

`Scripts/BuildRelease.ps1`이 설치본을 실행해 튜토리얼을 시작부터 출구까지 자동으로 플레이합니다. 입력은 실제 키 이벤트이고, 순간이동 없이 걸어갑니다.

| 항목 | 결과 |
| --- | --- |
| 날짜 | 2026-11-06 |
| PC | Windows 11 Pro, RTX 4080 SUPER, RAM 32GB (개발 PC) |
| 빌드 | 쿡 708개, 오류 0개, 경고 0개, 2분 6초 |
| 설치본 크기 | zip 520MB, 압축 해제 793MB |
| 자동 플레이 | **PASS**, 99초, 목표 9/9 달성, 쓰러짐 0회 |
| 지나간 단계 | 걷기 → 점프 구역 → 마법 2회 → 첫 박쥐 처치 → 카드 등록 → Y 소환 → 소환수가 피해 → 3마리 처치 → 출구 |
| 내비 메시 | 사냥 구역에서 확인 |
| Esc 두 번 종료 | 정상 |
| 크래시 | 없음 |
| zip 사본 재실행 | **PASS**, 새 폴더에 zip을 풀어 실행, 65초, 쓰러짐 0회 |

이 점검으로 **확인되지 않는 것:** 소리가 실제로 들리는지, 조작감, 사람이 안내를 이해하는지, 다른 PC에서 실행되는지. 개발 PC에는 언리얼과 VC++ 런타임이 이미 깔려 있어서 클린 설치를 대신할 수 없습니다.
